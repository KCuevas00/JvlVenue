# JVL Venue Website

A responsive, high-end website for **JVL Venue** — an intimate salon and reception party hall in **Plano, IL** (capacity: up to 75 guests).

## Palette & Styling
- **Base**: Ink (`#121212`), Charcoal (`#222222`), White (`#FFFFFF`), Off-white (`#F8F8F7`)
- **Accents**: Gold (`#C5A059`, `--gold`), Silver (`#C0C0C0`, `--silver`), Black
- All previous red buttons, badges, icons, and lattice patterns replaced with gold/black/silver luxury styling.
